# 📦 Product Service

The **Product Service** manages the core commerce catalog, including products, categories, and attributes.

## 🛠️ Tech Stack

- **Framework**: NestJS
- **Data Store**: PostgreSQL (Sharded)
- **Cache**: Redis

## 📋 Responsibilities

1. **Catalog Management**: CRUD operations for products and their metadata.
2. **Dynamic Search**: Efficient querying through high-scale catalogs.
3. **Database Sharding**: Managing horizontal partitions for massive datasets.
